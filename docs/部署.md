# MoneyAI 生产部署修改清单

适用当前服务器：

- 域名：`https://money-ai.cn/`
- 项目路径：`/root/workplace/moneyai`
- Node 服务：`127.0.0.1:3000`
- Nginx 配置：`/etc/nginx/sites-enabled/money-ai.cn`
- 进程名：`moneyai`

## 1. 代码上传

从本机同步代码到 ECS：

```bash
rsync -av \
  --exclude node_modules \
  --exclude .git \
  --exclude logs \
  --exclude .env \
  --exclude data/store.json \
  /Users/zhangqilai/project/learn-ai/ \
  root@你的ECS公网IP:/root/workplace/moneyai/
```

不要覆盖：

- `.env`：生产环境变量、支付宝密钥、SMTP 授权码。
- `data/store.json`：用户、会话、订单数据。

## 2. 必须确认的 `.env`

服务器执行：

```bash
cd /root/workplace/moneyai
grep -E '^(PORT|PUBLIC_BASE_URL|SITE_URL|CORS_ORIGIN|ALIPAY_NOTIFY_URL|PRICE_MARKUP_RATE)=' .env
```

必须是：

```env
PORT=3000
PUBLIC_BASE_URL=https://money-ai.cn
SITE_URL=https://money-ai.cn
CORS_ORIGIN=https://money-ai.cn
ALIPAY_NOTIFY_URL=https://money-ai.cn/api/alipay/notify
PRICE_MARKUP_RATE=0.2
```

支付宝相关变量也必须配置：

```env
ALIPAY_APP_ID=
ALIPAY_PRIVATE_KEY=
ALIPAY_PUBLIC_KEY=
ALIPAY_GATEWAY=https://openapi.alipay.com/gateway.do
```

`PUBLIC_BASE_URL` 会决定支付宝支付后的同步回跳地址，必须是线上 HTTPS 域名。

## 3. Nginx 需要补齐的头

你当前 Nginx 配置基本可用，建议确认 HTTPS server 的 `location /` 包含：

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_cache_bypass $http_upgrade;
}
```

修改后执行：

```bash
nginx -t
systemctl reload nginx
```

## 4. 构建和重启

服务器执行：

```bash
cd /root/workplace/moneyai
npm ci
npm run check:catalog
npm run build
pm2 reload moneyai --update-env
```

如果商品数据不存在或过旧：

```bash
npm run sync:products
npm run check:catalog
npm run build
pm2 reload moneyai --update-env
```

## 5. PM2 配置要匹配路径

`ecosystem.config.cjs` 里的 `cwd` 和日志路径应使用：

```js
module.exports = {
  apps: [
    {
      name: "moneyai",
      script: "server.cjs",
      cwd: "/root/workplace/moneyai",
      instances: 1,
      exec_mode: "fork",
      env: {
        NODE_ENV: "production",
        PORT: "3000"
      },
      error_file: "/root/workplace/moneyai/logs/pm2-error.log",
      out_file: "/root/workplace/moneyai/logs/pm2-out.log",
      time: true
    }
  ]
};
```

启动或恢复开机自启：

```bash
pm2 start ecosystem.config.cjs
pm2 save
pm2 startup systemd -u root --hp /root
```

## 6. 支付宝上线检查

小额真实支付前确认：

```bash
curl https://money-ai.cn/api/health
curl -I https://money-ai.cn/orders
grep -E 'PUBLIC_BASE_URL|ALIPAY_NOTIFY_URL|ALIPAY_APP_ID' /root/workplace/moneyai/.env
```

完成支付后看日志：

```bash
tail -n 200 /root/workplace/moneyai/logs/server.log
```

正常应出现：

```text
orders.alipay.created
orders.alipay_return.confirmed
orders.my.success
```

如果同步回跳签名失败，但支付宝交易查询确认成功，会出现：

```text
orders.alipay_return.query_confirmed
```

这表示后端已经通过支付宝交易查询把订单确认成已支付。

## 7. 常用排查

```bash
pm2 status
pm2 logs moneyai
curl http://127.0.0.1:3000/api/health
curl https://money-ai.cn/api/health
tail -n 100 /var/log/nginx/error.log
tail -n 100 /root/workplace/moneyai/logs/server.log
```

订单接口验证需要登录 token，通常通过页面验证即可；后台日志里的 `orders.my.success` 会显示当前账号返回的订单数量。
